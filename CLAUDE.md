# auspex-otel

Read `CONTRIBUTING.md` first: it holds the project philosophy, the
Design/Validate/Implement/Test/Verify workflow, and the review-clean commit
discipline. `just ci` is the gate before any significant commit. The default
branch is `latest`.

## Project memory

This project uses the trivia MCP. All memories are tagged `project:auspex-otel`
and follow the trivium taxonomy (seeds, `habits/<theme>` hubs, and
`worked` / `avoid` / `learned` spokes). Themes: tooling, testing, rust-idioms,
exporter, hotpath, review. Open sessions with `session-start`, close them with
`session-retro`, and run `memory-gardening` when lessons stop surfacing.
